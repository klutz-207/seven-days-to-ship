# 背景音乐文件

请在此目录下放置以下 mp3 文件：

| 文件名 | 场景 | 建议风格 |
|--------|------|----------|
| `start.mp3` | 开始页面 + 命名 | 轻柔、神秘 |
| `narration.mp3` | 上帝推演 + 角色卡片 | 史诗、叙事感 |
| `day-transition.mp3` | 天数过渡 | 短过渡音效 |
| `daily-note.mp3` | 每日计划 | 轻快、日常感 |
| `corridor.mp3` | 走廊场景 | 脚步声、环境音 |
| `room.mp3` | 房间场景（工作） | 专注、Lo-fi |
| `ending.mp3` | 结局报告 | 成就感或反思 |

文件格式：mp3，建议 128kbps 以上，单文件 2-5MB 以内。

可选的免费音乐来源：
- https://pixabay.com/music/
- https://freesound.org/
- https://incompetech.com/
